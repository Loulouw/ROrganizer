Why this one

A tool that listens to your keyboard should be open to inspection.

Inspired by nAiO Organizer, which the Dofus community knows well — but entirely open source. For a program that watches your shortcuts and your windows, that changes everything.

The code is public
Anyone can read it and confirm there is no keylogger, no telemetry, no hidden connection.
The file you download is verifiable
Every release is built by GitHub from the public source, never on a personal machine. It ships with a proof of origin you can check with one command — and that nobody else can forge.
It won't die with me
If I stop working on it, anyone can pick it up. Your tool does not depend on one person.

It does not read the game, modify it, or send it anything. ROrganizer only listens for your shortcuts and brings the right window forward — exactly what Alt+Tab does on Windows, or Cmd+Tab on a Mac.

Privacy

Offline, and you can check it.

  • The app never connects to any server.
  • It does not touch Dofus. It does not read the game, modify it, or send it anything. It listens for your shortcuts and brings the right window forward.
  • No keystroke is ever recorded. Shortcuts are recognised on the fly, then forgotten.
  • The only file written to your disk is its own configuration: your shortcuts, your language, your theme.

What it does

Eight things, done well.

  • Automatic detectionYour accounts appear as soon as they launch, on Dofus, Dofus Retro and Dofus Experimental.
  • One shortcut per accountA keyboard key or a mouse button. F1 Mb4
  • Cycle through accountsA next shortcut, a previous one, and you cycle through your whole team.
  • Drag and dropArrange your accounts in whatever order suits you.
  • Light or dark themeIn French, English or Spanish.
  • Quiet, where you want itMinimized to the system tray or to the taskbar (on a Mac: the menu bar or the Dock), enabled with one click.
  • A tidy taskbarOn Windows, one click puts the Dofus windows of the taskbar in the order of your accounts.
  • Set up your wayShortcuts in Dofus only, window always on top or not, position remembered from one launch to the next.

Getting started

Three steps, no installation.

  1. Download

    Grab the file for your system from the releases page: the .exe for Windows, the .dmg for Mac. No installer, no dependencies.

  2. Run

    On Windows, double-click it. On a Mac, open the .dmg and drag ROrganizer into Applications. ROrganizer detects accounts that are already open on its own.

  3. Configure

    Click “set” next to an account, then press the key you want to give it.

Verify

Two commands to be sure of what you are running.

GitHub shows the checksum of every published file next to its name. Compare it with yours, on Windows (PowerShell) or on a Mac (Terminal):

> Get-FileHash .\ROrganizer-<version>-x86_64-windows.exe -Algorithm SHA256
$ shasum -a 256 ROrganizer-<version>-universal-macos.dmg

And from version 1.3.0 onwards, every file carries a proof of origin signed by GitHub, binding it to the public source and the published tag:

> gh attestation verify .\ROrganizer-<version>-x86_64-windows.exe --repo Loulouw/ROrganizer
$ gh attestation verify ROrganizer-<version>-universal-macos.dmg --repo Loulouw/ROrganizer

The full procedure is documented in the project's security policy.

Questions

What people ask me most.

Do I have to configure each account one by one?

No. ROrganizer automatically detects all your accounts as soon as they launch, on the standard client as well as Dofus Retro and Dofus Experimental. You only assign a shortcut to each one, and it is remembered. Retro accounts appear without a class icon: their window does not state the class.

Could I get banned for using it?

ROrganizer does not interact with Dofus. It does not read the game, modify it, or send it any command. It brings a window to the front — exactly what Alt+Tab does on Windows, or Cmd+Tab on a Mac. That said, using third-party tools remains at your own risk under Ankama's terms of service.

Do my shortcuts work while I'm in game?

Yes. They are system-wide hotkeys, so they work whichever window is in the foreground. If you'd rather have them work in Dofus only, tick the option in the settings (the gear). One caveat on Windows: if Dofus runs as administrator, run ROrganizer as administrator too.

Windows shows a blue warning on first launch — is that normal?

Yes. ROrganizer is not signed with a code-signing certificate, which costs several hundred euros a year and is not justifiable for a free project. Windows SmartScreen warns as a precaution about any program it rarely sees. Click “More info”, then “Run anyway”.

On a Mac, macOS refuses to open the app — is that normal?

Yes. ROrganizer is not signed by Apple, which requires a paid developer subscription. On the first launch of each downloaded version, open System Settings → Privacy & Security, scroll down to the message about ROrganizer and click “Open Anyway”.

ROrganizer then shows a banner asking for the Accessibility permission: it is what lets it see the Dofus windows, listen for your shortcuts and bring the right window forward. Click “Open settings”, then enable ROrganizer in the list. You grant it once; it stays valid for later versions.

My antivirus flags a “trojan” — is the app dangerous?

No, it is a false positive. To trigger your shortcuts even when Dofus is in the foreground, ROrganizer has to listen to the keyboard and mouse system-wide, then bring a window forward. An antivirus that judges a program by what it looks like, without reading its code, cannot tell that mechanism apart from spyware. The name it shows — often Wacatac — is a generic label assigned automatically, not the identification of a known virus.

What you can check yourself: the source is public, no keystroke is recorded, and the app connects to no server — observable in the Windows Resource Monitor. Every false positive is reported to Microsoft when a release ships, but the correction takes a few days to propagate. In the meantime you can add the file as an exclusion in your antivirus, after checking its checksum.

How do I uninstall it?

On Windows, delete the file. Your preferences live in %APPDATA%\rorganizer\ — delete that folder for a full clean-up. No registry key modified, no service installed. On a Mac, move ROrganizer to the Trash from Applications, then delete ~/Library/Application Support/rorganizer/ if you want to erase your preferences.

Beware of fake downloads

ROrganizer is available only from the releases page of the GitHub repository, as a single file per system: an .exe for Windows, a .dmg for macOS. A .dmg is legitimate only if it comes from that page.

This website hosts no files. The download button sends you to GitHub — that is expected, and it is the only legitimate behaviour.

It is never distributed:

  • inside a .zip, .rar or .7z archive — least of all a password-protected one;
  • as a .bat, .cmd, .ps1 or .vbs script;
  • through an installer or a setup.exe;
  • from a file host, a Discord link, a forum or a mirror site.

An archive password shared separately — in a video, a comment, a private message — exists to defeat the file host's automated malware scanning. That alone is a red flag.

Any file carrying the ROrganizer name that does not match this description did not come from me, wherever you found it.
